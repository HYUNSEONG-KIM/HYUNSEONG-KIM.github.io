# Projects

My projects range from quantum algorithms and scientific computing to tools for making books. Alongside my research software, I develop personal publishing and bookbinding projects under the name HornPenguin.

## Quantum and scientific software

### [Tensorized Pauli Composer](https://github.com/OptTrot/Tensorized-Pauli-Composer)

An implementation of a Hamiltonian matrix-construction algorithm for weighted Pauli polynomials, with benchmark data and a technical preprint.

### [OptTrot](https://github.com/OptTrot/OptTrot)

Python and C routines for Pauli-group algebra, Hamiltonian decomposition, operator conversion, and Trotter-circuit generation.

### [TorchPenny](https://github.com/HYUNSEONG-KIM/TorchPenny)

A lightweight framework for defining PennyLane quantum circuits as composable PyTorch modules, with automatic management of trainable circuit parameters.

### [UILC](https://github.com/HYUNSEONG-KIM/UILC)

Numerical routines for designing linear and rectangular LED arrays with uniform irradiance over a target region.

## Personal projects

### [HornPenguin]({% link docs/Projects/HornPenguin.md %})

My personal publishing and bookbinding initiative, bringing together book design, printing, and open-source software.

### [Booklet]({% link docs/Projects/HornPenguin.md %}#booklet)

A Python application for PDF imposition and book-signature generation. It arranges pages for printing and folding, with options for signature size, page dimensions, and printing marks.
